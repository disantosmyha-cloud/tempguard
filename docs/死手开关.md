## 接口

```python
class DeadManSwitch:
    def poll(self) -> Optional[DeadManEvent]:
        ...
```

`DeadManEvent` 包含：

- `source`：`mock` / `serial` / `http` / `gpio`
- `reason`
- `at`

## 现有实现

- `NullDeadManSwitch`：没有硬件，永远不触发；
- `MockDeadManSwitch`：手动 `trigger()`，或 `timeout_seconds` 内未 `confirm()` 触发。

## 演练

```powershell
python tools/deadman_sim.py
```

按回车触发一次 TRIP，走当前 alertd 的 email/QQ 通道；不会启动/停止服务。

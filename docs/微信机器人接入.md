# 接入企业微信群机器人

> 如果你的微信已经接在 AstrBot 里，优先看 [AstrBot 告警接入](AstrBot告警接入.md)，不用再单独建企业微信机器人。
>
> 本文是“不经过 AstrBot，直接调企业微信 Webhook”的备用方案。

tempguard 通过**企业微信群机器人**的官方 Webhook 发告警。

为什么不用个人微信机器人：个人微信没有官方机器人接口，第三方方案（Wechaty / itchat 等）依赖非官方协议，容易掉线，也有封号风险。企业微信群机器人是官方功能，稳定、免费、不需要额外 Python 包。

---

## 1. 创建群机器人

1. 打开企业微信，进入一个群（可以自己建一个只有自己的群）；
2. 群右上角 **...** → **群机器人** → **添加机器人**；
3. 给机器人起个名字，例如 `temguard`；
4. 复制生成的 **Webhook 地址**，格式类似：

```text
https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

这个地址就是密钥，不要发到公开群、截图或 GitHub。

---

## 2. 填到本机配置

编辑 [config.local.yaml](../config.local.yaml)：

```yaml
notify:
  print: true
  wechat:
    webhook: "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=你的key"
    mentioned_list: []         # 可选：["@all"] 或 ["zhangsan"]
    mentioned_mobile_list: []  # 可选：["13800138000"]
    timeout_seconds: 5
```

注意：

- 只填 `config.local.yaml`，不要填公开的 `config.yaml`；
- `config.local.yaml` 已被 `.gitignore` 忽略，不会上传；
- 公开的 `config.yaml` 里 `webhook` 保持空字符串。

---

## 3. 测试

```powershell
cd C:\path\to\tempguard
python main.py --test-notify
```

成功：

```text
微信机器人测试消息发送成功
```

失败：

```text
微信机器人测试消息发送失败：检查 notify.wechat.webhook 和网络
```

如果失败，先检查：

1. Webhook 是否完整复制；
2. 电脑能否访问 `qyapi.weixin.qq.com`；
3. 机器人是否被移出群；
4. key 是否失效。

---

## 4. 会收到什么消息

正常状态变化时才会发，不会每 5 秒刷屏：

```text
2026-10-22 21:00:00 [警告] 温度警告：CPU 91.0°C ≥ 警告线 90°C
2026-10-22 21:10:00 [熔断] 持续高温，终止进程。CPU 94.0°C 已连续 1200s ≥ 93°C
2026-10-22 21:10:01 [信息] 已终止 blender.exe(48368)
2026-10-22 21:20:00 [熔断] 危险高温，需要关机。CPU 96.0°C 连续 3 次 ≥ 95°C
```

- 温度正常时不发；
- 从异常恢复时发一条“温度恢复正常”；
- 启动保护期内即使假高温，也只发警告，不会发关机通知。

---

## 5. @ 人

`mentioned_list` 支持企业微信成员 UserID 或 `@all`：

```yaml
mentioned_list: ["@all"]
```

`mentioned_mobile_list` 支持手机号：

```yaml
mentioned_mobile_list: ["13800138000"]
```

不要滥用 `@all`，否则群里其他人会烦。

---

## 6. 频率和超时

- 企业微信群机器人默认限制约 **20 条/分钟**；
- tempguard 只在状态变化时发消息，正常不会触发限制；
- 微信请求在后台线程发送，超时时间默认 5 秒，不会卡住温度采样和熔断动作；
- 发送失败不会让主程序崩溃，失败信息不会打印 Webhook 密钥。

---

## 7. 安全提醒

1. **Webhook 就是密码**：泄露后别人可以往你的群里发消息；
2. 只放在 `config.local.yaml`，不要提交 GitHub；
3. 如果误提交了：
   - 立刻在企业微信里删除该机器人；
   - 重新创建一个机器人，换新 key；
   - 用 `git filter-repo` 或联系 GitHub 清理历史；
4. 公开仓库的 `config.yaml` 永远保持：

```yaml
webhook: ""
```

---

## 8. 常见错误码

企业微信返回 `errcode` 不等于 0 时，tempguard 视为发送失败。

| errcode | 含义 | 处理 |
|---|---|---|
| `93000` | webhook key 无效 | 重新复制/重建机器人 |
| `45009` | 接口调用超过限制 | 降低告警频率，等一分钟 |
| `40058` | 消息内容不合法 | 检查是否被截断或包含不支持内容 |

程序不会把错误码打印到控制台，避免泄露密钥；需要排查时可以在 `core/notify.py` 的 `_push_wechat` 里临时打印，但不要把 key 打出来。
